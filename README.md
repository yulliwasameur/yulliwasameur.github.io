# Site académique de Yulliwas Ameur

Ce dépôt public alimente [yulliwasameur.github.io](https://yulliwasameur.github.io/), le site académique de Yulliwas Ameur, enseignant-chercheur en cybersécurité à Efrei et docteur en informatique du Cnam.

Le site présente :

- les publications scientifiques vérifiées avec leurs DOI, notices HAL et artefacts ;
- les axes de recherche, encadrements et activités de service scientifique ;
- les enseignements, conférences et analyses professionnelles ;
- une sélection de logiciels de recherche et un CV public assaini.
